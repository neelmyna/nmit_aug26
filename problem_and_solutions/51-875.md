## Problem Description

Koko has several piles of bananas.

She can eat at a fixed speed `k` bananas per hour.

Find the **minimum eating speed** required to finish all bananas within `h` hours.

---

## Example

**Input**

```text
piles = [3,6,7,11]

h = 8
```

**Output**

```text
4
```

---

## Observation
```
The answer lies between:
  * 1 banana/hour
  * Maximum pile size
This allows Binary Search on the answer.
```
---

## Solution Idea
```
Guess an eating speed.
Calculate total hours needed.
If possible,
try a smaller speed.
Otherwise,
increase the speed.
```
---

## Algorithm

1. Set search range.
2. Binary search speed.
3. Compute required hours.
4. Update search range.
5. Return minimum valid speed.

---

## Pseudocode

```text
left = 1
right = maximum pile
While left < right
    mid = (left + right) / 2
    Compute hours
    If hours <= h
        right = mid
    Else
        left = mid + 1
Return left
```

# Implementation
Here are the translations of your binary search logic into Python, Java, and C++.

To make the code fully functional for the **Koko Eating Bananas** problem, the "Compute hours" step has been implemented using a loop with ceiling division.

### Python

```python
import math

def min_eating_speed(piles: list[int], h: int) -> int:
    left = 1
    right = max(piles)    
    while left < right:
        mid = (left + right) // 2        
        # Compute total hours needed at speed 'mid'
        hours = 0
        for pile in piles:
            hours += math.ceil(pile / mid)            
        if hours <= h:
            right = mid
        else:
            left = mid + 1            
    return left

```

---

### Java

*Note: In Java, we use `long` for the `hours` variable to prevent integer overflow on very large inputs. We also use the math trick `(pile + mid - 1) / mid` to perform ceiling division using integers, which is much faster than casting to `double` and using `Math.ceil`.*

```java
class Solution {
    public int minEatingSpeed(int[] piles, int h) {
        int left = 1;
        int right = 0;        
        // Find the maximum pile for the upper bound
        for (int pile : piles) {
            right = Math.max(right, pile);
        }        
        while (left < right) {
            // Safer way to calculate mid to avoid integer overflow
            int mid = left + (right - left) / 2;             
            // Compute total hours needed at speed 'mid'
            long hours = 0; 
            for (int pile : piles) {
                hours += (pile + mid - 1) / mid; // Integer ceiling division trick
            }            
            if (hours <= h) {
                right = mid;
            } else {
                left = mid + 1;
            }
        }        
        return left;
    }
}

```

*Note: Similar to Java, we use `long long` for `hours` and integer ceiling division for performance.*

#include <vector>
#include <algorithm>

class Solution {
public:
    int minEatingSpeed(std::vector<int>& piles, int h) {
        int left = 1;
        // Find the maximum pile for the upper bound
        int right = *std::max_element(piles.begin(), piles.end());        
        while (left < right) {
            // Safer way to calculate mid to avoid integer overflow
            int mid = left + (right - left) / 2;            
            // Compute total hours needed at speed 'mid'
            long long hours = 0;
            for (int pile : piles) {
                hours += (pile + mid - 1) / mid; // Integer ceiling division trick
            }            
            if (hours <= h) {
                right = mid;
            } else {
                left = mid + 1;
            }
        }        
        return left;
    }
};
