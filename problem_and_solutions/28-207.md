## Problem Description

There are `numCourses` courses labeled from `0` to `numCourses - 1`.

Some courses have prerequisites.

Determine whether it is possible to finish all courses.

---

## Example

**Input**

```text
numCourses = 2

prerequisites = [[1,0]]
```

**Output**

```text
true
```

Explanation

```text
Take course 0

↓

Take course 1
```

## Example 2

**Input**

```text
numCourses = 2

prerequisites = [[1,0],[0,1]]
```

**Output**

```text
false
```

Explanation

```text
0 depends on 1

1 depends on 0

Cycle exists
```

---

## Observation

Courses and prerequisites form a **Directed Graph**.

If the graph contains a **cycle**, all courses cannot be completed.

---

## Solution Idea

Use **Topological Sort (Kahn's Algorithm)**.

* Compute the indegree of every course.
* Insert courses with indegree 0 into a queue.
* Remove them one by one and reduce indegrees of dependent courses.
* If all courses are processed, return true.

---

## Algorithm

1. Build graph.
2. Compute indegree.
3. Insert indegree 0 nodes into queue.
4. Process queue.
5. Count processed courses.
6. If count equals total courses, return true.

---

## Pseudocode

```text
Build graph

Compute indegree

Insert all indegree 0 nodes into queue

count = 0

While queue is not empty

    Remove course

    count++

    Reduce indegree of neighbors

    If neighbor indegree becomes 0

        Insert into queue

If count == total courses

    Return true

Else

    Return false
```

Here is the translation of your topological sort pseudocode (commonly known as Kahn's Algorithm, often used for "Course Schedule" problems) into Java, C++, and Python.

These implementations assume a standard problem format where you are given the total number of courses (`numCourses`) and a list of `prerequisites`, where `[a, b]` indicates that you must take course `b` first to take course `a` (a directed edge from `b` to `a`).

### Java

```java
import java.util.*;

class Solution {
    public boolean canFinish(int numCourses, int[][] prerequisites) {
        // Build graph and compute indegree
        List<List<Integer>> adj = new ArrayList<>();
        for (int i = 0; i < numCourses; i++) {
            adj.add(new ArrayList<>());
        }
        
        int[] indegree = new int[numCourses];
        for (int[] pre : prerequisites) {
            int course = pre[0];
            int prereq = pre[1];
            adj.get(prereq).add(course);
            indegree[course]++;
        }
        
        // Insert all indegree 0 nodes into queue
        Queue<Integer> queue = new LinkedList<>();
        for (int i = 0; i < numCourses; i++) {
            if (indegree[i] == 0) {
                queue.offer(i);
            }
        }
        
        int count = 0;
        
        // While queue is not empty
        while (!queue.isEmpty()) {
            int currentCourse = queue.poll(); // Remove course
            count++;
            
            // Reduce indegree of neighbors
            for (int neighbor : adj.get(currentCourse)) {
                indegree[neighbor]--;
                // If neighbor indegree becomes 0, insert into queue
                if (indegree[neighbor] == 0) {
                    queue.offer(neighbor);
                }
            }
        }
        
        // If count == total courses, return true; Else return false
        return count == numCourses;
    }
}

```

```cpp
#include <vector>
#include <queue>

class Solution {
public:
    bool canFinish(int numCourses, std::vector<std::vector<int>>& prerequisites) {
        // Build graph and compute indegree
        std::vector<std::vector<int>> adj(numCourses);
        std::vector<int> indegree(numCourses, 0);
        
        for (const auto& pre : prerequisites) {
            int course = pre[0];
            int prereq = pre[1];
            adj[prereq].push_back(course);
            indegree[course]++;
        }
        
        // Insert all indegree 0 nodes into queue
        std::queue<int> q;
        for (int i = 0; i < numCourses; i++) {
            if (indegree[i] == 0) {
                q.push(i);
            }
        }
        
        int count = 0;
        
        // While queue is not empty
        while (!q.empty()) {
            int currentCourse = q.front();
            q.pop(); // Remove course
            count++;
            
            // Reduce indegree of neighbors
            for (int neighbor : adj[currentCourse]) {
                indegree[neighbor]--;
                // If neighbor indegree becomes 0, insert into queue
                if (indegree[neighbor] == 0) {
                    q.push(neighbor);
                }
            }
        }
        
        // If count == total courses, return true; Else return false
        return count == numCourses;
    }
};
```

### Python

```python
from collections import deque

class Solution:
    def canFinish(self, numCourses: int, prerequisites: list[list[int]]) -> bool:
        # Build graph and compute indegree
        adj = [[] for _ in range(numCourses)]
        indegree = [0] * numCourses
        
        for course, prereq in prerequisites:
            adj[prereq].append(course)
            indegree[course] += 1
            
        # Insert all indegree 0 nodes into queue
        queue = deque()
        for i in range(numCourses):
            if indegree[i] == 0:
                queue.append(i)
                
        count = 0
        
        # While queue is not empty
        while queue:
            current_course = queue.popleft() # Remove course
            count += 1
            
            # Reduce indegree of neighbors
            for neighbor in adj[current_course]:
                indegree[neighbor] -= 1
                # If neighbor indegree becomes 0, insert into queue
                if indegree[neighbor] == 0:
                    queue.append(neighbor)
                    
        # If count == total courses, return true; Else return false
        return count == numCourses
```
