# LeetCode 206. Reverse Linked List

**Difficulty:** Easy

**Category / Pattern**

* Linked List
* Recursion (Alternative)

---

## Problem Description

Reverse a singly linked list and return the new head.

---

## Example

**Input**

```text
1 → 2 → 3 → 4 → 5
```

**Output**

```text
5 → 4 → 3 → 2 → 1
```

---

## Observation

Each node should point to its previous node instead of the next node.

---

## Solution Idea
```
Maintain three pointers:
* Previous
* Current
* Next
Reverse one link at a time.
```
---

## Algorithm
```
1. Initialize previous as NULL.
2. Traverse the list.
3. Store next node.
4. Reverse current link.
5. Move all pointers.
6. Return previous.
```
---

## Pseudocode

```text
previous = NULL
current = head
While current exists
    next = current.next
    current.next = previous
    previous = current
    current = next
Return previous
```

# Implementation
This pseudocode represents the standard in-place algorithm for reversing a singly linked list (LeetCode 206: Reverse Linked List).

Here are the translations into Java, C++, and Python.

### Java

```java
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode(int x) { val = x; }
 * }
 */
class Solution {
    public ListNode reverseList(ListNode head) {
        ListNode previous = null;
        ListNode current = head;        
        while (current != null) {
            ListNode next = current.next;
            current.next = previous;
            previous = current;
            current = next;
        }        
        return previous;
    }
}
```

### C++

```cpp
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode(int x) : val(x), next(nullptr) {}
 * };
 */
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        ListNode* previous = nullptr;
        ListNode* current = head;        
        while (current != nullptr) {
            ListNode* next = current->next;
            current->next = previous;
            previous = current;
            current = next;
        }        
        return previous;
    }
};
```

### Python 3

*Note: In Python, `next` is a built-in function, so it is best practice to name the temporary variable `next_node` to avoid shadowing the built-in name.*

```python
# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        previous = None
        current = head        
        while current:
            next_node = current.next
            current.next = previous
            previous = current
            current = next_node            
        return previous
```
