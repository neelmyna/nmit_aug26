# LeetCode 98. Validate Binary Search Tree

**Difficulty:** Medium

**Category / Pattern**

* Binary Search Tree
* DFS

---

## Problem Description
```
Given the root of a binary tree, determine whether it is a **valid Binary Search Tree (BST)**.
A BST satisfies:
* All values in the left subtree are smaller than the node.
* All values in the right subtree are greater than the node.
* Both left and right subtrees are also BSTs.
```
---

## Example

**Input**

```text
    2
   / \
  1   3
```

**Output**

```text
true
```

---

## Observation
```
Comparing a node only with its immediate children is **not enough**.
Each node must satisfy a valid **minimum and maximum range**.
```
---

## Solution Idea
```
Use DFS and maintain the valid range for every node.
* Left child → maximum becomes current node value.
* Right child → minimum becomes current node value.
If a node violates the range, return false.
```
---

## Algorithm
```
1. Start from the root.
2. Pass minimum and maximum limits.
3. Check whether current value lies within the range.
4. Recursively validate left and right subtrees.
5. Return true only if both subtrees are valid.
```
---

## Pseudocode
```
Function isValidBST(root):
    Return Validate(root, -INFINITY, +INFINITY)

Function Validate(node, minimum, maximum):
    If node is NULL:
        Return true
    If node.value <= minimum OR node.value >= maximum:
        Return false
    Return Validate(node.left, minimum, node.value) AND 
           Validate(node.right, node.value, maximum)
```

## Dry Run

```text
    5
   / \
  1   4
     / \
    3   6
```

Node **3** is in the right subtree of **5** but is smaller than **5**.

Therefore,

```text
Invalid BST
```

# Implementation
This pseudocode represents a classic recursive depth-first search approach to validate if a binary tree is a valid Binary Search Tree (LeetCode 98: Validate Binary Search Tree).

*Note: In Java and C++, I used `long` and `long long` for the `minimum` and `maximum` parameters. This is a common requirement because a tree node could contain `Integer.MIN_VALUE` or `Integer.MAX_VALUE`, and using standard 32-bit integers for the bounds would cause overflow issues during the comparison.*

Here are the translations into Java, C++, and Python.

### Java

```java
/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode(int x) { val = x; }
 * }
 */
class Solution {
    public boolean isValidBST(TreeNode root) {
        // Initialize with Long min and max to prevent integer overflow on edge cases
        return validate(root, Long.MIN_VALUE, Long.MAX_VALUE);
    }
    private boolean validate(TreeNode node, long minimum, long maximum) {
        if (node == null) {
            return true;
        }
        if (node.val <= minimum || node.val >= maximum) {
            return false;
        }
        return validate(node.left, minimum, node.val) && 
               validate(node.right, node.val, maximum);
    }
}

```

### C++

```cpp
#include <climits>

/**
 * Definition for a binary tree node.
 * struct TreeNode {
 *     int val;
 *     TreeNode *left;
 *     TreeNode *right;
 *     TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
 * };
 */
class Solution {
public:
    bool isValidBST(TreeNode* root) {
        // Use long long to handle 32-bit integer limits securely
        return validate(root, LONG_MIN, LONG_MAX);
    }
private:
    bool validate(TreeNode* node, long long minimum, long long maximum) {
        if (node == nullptr) {
            return true;
        }
        if (node->val <= minimum || node->val >= maximum) {
            return false;
        }
        return validate(node->left, minimum, node->val) && 
               validate(node->right, node->val, maximum);
    }
};

```

### Python 3

```python
from typing import Optional

# Definition for a binary tree node.
# class TreeNode:
#     def __init__(self, val=0, left=None, right=None):
#         self.val = val
#         self.left = left
#         self.right = right

class Solution:
    def isValidBST(self, root: Optional[TreeNode]) -> bool:
        # Use Python's infinity for initial boundary conditions
        return self.validate(root, float('-inf'), float('inf'))
    def validate(self, node: Optional[TreeNode], minimum: float, maximum: float) -> bool:
        if not node:
            return True
        if node.val <= minimum or node.val >= maximum:
            return False
        return (self.validate(node.left, minimum, node.val) and 
                self.validate(node.right, node.val, maximum))
```
