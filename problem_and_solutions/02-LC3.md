# LeetCode 3. Longest Substring Without Repeating Characters

**Difficulty:** Medium

**Category / Pattern:** Sliding Window, Hashing

---

# Problem Description

Given a string `s`, find the length of the **longest substring** without repeating characters.

A **substring** is a contiguous sequence of characters within a string.

Return the length of the longest substring that contains only unique characters.

---

# Example 1

**Input**

```text
s = "abcabcbb"
```

**Output**

```text
3
```

### Explanation

The longest substring without repeating characters is:

```text
"abc"
```

Length = **3**

Other substrings like `"bca"` and `"cab"` also have length **3**, but none are longer.

# Example 2

**Input**

```text
s = "bbbbb"
```

**Output**

### Explanation

The longest substring without repetition is:

```text
"b"
```

Length = **1**

# Constraints

```text
0 <= s.length <= 5 × 10^4

```

# Observation
```text
A straightforward approach is to generate every possible substring and check whether all characters are unique.
Example: s = "abcabcbb"
Possible substrings:
a
ab
abc
abca
abcab
...
Checking every substring requires two nested loops and an additional uniqueness check.
Time Complexity: O(n³)
This is too slow for large strings.
```
---

# Key Idea
```
Instead of checking every substring, maintain a **window** containing only unique characters.
If a duplicate character appears:
    * Remove characters from the left side of the window.
    * Continue until the duplicate is removed.
This technique is called the **Sliding Window**.
To quickly determine whether a character already exists in the current window, use a **Hash Set**.
```
---

# Sliding Window Concept
```
Consider s = "abcabcbb"
Initially   Window = ""
Add characters one by one.
-----------------------------------
char Window Unique ✔ Duplicate!
-----------------------------------
a    "a"    ✔
b    "ab"   ✔
c    "abc"  ✔
Maximum length 3
Next character
a    "abca" !
Move the left pointer until the duplicate is removed.
Remove a
     "bca"  ✔
Now every character is unique again.
Continue the same process until the end of the string.
```
---

# Algorithm
```
1. Create an empty Hash Set.
2. Initialize two pointers: * `left = 0` * `right = 0`
3. Expand the window by moving `right`.
4. If the current character already exists in the Hash Set:
   * Remove characters from the left.
   * Move `left` forward.
5. Add the current character.
6. Update the maximum window length.
7. Continue until the string ends.
```
---

# Pseudocode

```text
seen = hashSet()
left = 0, maximumLength = 0
For right = 0 to length - 1
    While s[right] in hash set
        seen.remove(s[left])
        left = left + 1
    seen.add(s[right])
    currentLength = right - left + 1
    maximumLength = maximum of maximumLength and currentLength
Return maximumLength
```

# Python Solution (LeetCode)

```python
class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        seen = set()
        left = 0
        maximum = 0
        for right in range(len(s)):
            while s[right] in seen:
                seen.remove(s[left])
                left += 1
            seen.add(s[right])
            maximum = max(maximum, right - left + 1)
        return maximum
```

# Java Solution (LeetCode)

```java
import java.util.HashSet;
class Solution {
    public int lengthOfLongestSubstring(String s) {
        HashSet<Character> set = new HashSet<>();
        int left = 0;
        int maximum = 0;
        for (int right = 0; right < s.length(); right++) {
            while (set.contains(s.charAt(right))) {
                set.remove(s.charAt(left));
                left++;
            }
            set.add(s.charAt(right));
            maximum = Math.max(maximum, right - left + 1);
        }
        return maximum;
    }
}
```

# C++ Solution (LeetCode)

```cpp
class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        unordered_set<char> st;
        int left = 0;
        int maximum = 0;
        for (int right = 0; right < s.length(); right++) {
            while (st.count(s[right])) {
                st.erase(s[left]);
                left++;
            }
            st.insert(s[right]);
            maximum = max(maximum, right - left + 1);
        }
        return maximum;
    }
};
```

# Time Complexity
```text
Each character is:
* Added to the Hash Set at most once.
* Removed from the Hash Set at most once.
Therefore,
Time Complexity = O(n)
```

---

# Space Complexity
```text
The Hash Set stores only the unique characters in the current window.
If the character set size is fixed (e.g., ASCII), the space is effectively constant. In general:
Space Complexity = O(min(n, k))
where:
* `n` = length of the string
* `k` = number of distinct possible characters
```
---

# Why Does This Work?

The sliding window always maintains a substring with **no repeated characters**.

* The **right pointer** expands the window.
* The **left pointer** shrinks the window only when necessary.
* The Hash Set enables **O(1)** average-time checks for duplicates.

Each character enters and leaves the window at most once, giving an overall **O(n)** solution.

---

# Key Learning Points

* Sliding Window is used for problems involving contiguous subarrays or substrings.
* Hash Set provides constant-time membership checking.
* Two pointers (`left` and `right`) allow efficient expansion and contraction of the window.
* This pattern is widely used in string and array interview problems.

---

# Pattern Used

**Sliding Window + Hashing**

The sliding window maintains the current valid substring, while the Hash Set quickly checks whether adding the next character would create a duplicate.
