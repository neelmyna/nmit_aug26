# S.No. 34

# LeetCode 242. Valid Anagram

**Difficulty:** Easy

**Category / Pattern**

* Hashing
* String

---

## Problem Description

Given two strings `s` and `t`, determine whether `t` is an anagram of `s`.

---

## Example

**Input**

```text
s = "anagram"

t = "nagaram"
```

**Output**

```text
true
```

---

## Observation

Anagrams contain the same characters with the same frequencies.

---

## Solution Idea

Count the frequency of every character.

Compare the frequency counts.

---

## Algorithm

1. If lengths differ, return false.
2. Count characters of the first string.
3. Reduce counts using the second string.
4. If all counts become zero, return true.

---

## Pseudocode

```text
If lengths differ

    Return false

Count characters of first string

Reduce counts using second string

If every count is zero

    Return true

Else

    Return false
```

---

## Dry Run


Character counts become zero.

Answer

```text
true
```
