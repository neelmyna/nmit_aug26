# LeetCode 1. Two Sum

**Difficulty:** Easy

**Category / Pattern:** Hashing

---

# Problem Description

Given an array of integers `nums` and an integer `target`, return the **indices** of the two numbers such that they add up to `target`.

You may assume that:

* Exactly one valid solution exists.
* The same element cannot be used twice.
* The answer can be returned in any order.

---

# Example 1

**Input**

```
nums = [2,7,11,15]
target = 9
```

**Output**

```
[0,1]
```

### Explanation

```
nums[0] = 2
nums[1] = 7
2 + 7 = 9

Therefore, return [0,1].
```

# Constraints

```
2 <= nums.length <= 10^4
-10^9 <= nums[i] <= 10^9
-10^9 <= target <= 10^9
Exactly one valid answer exists.
```

---

# Observation

The straightforward approach is to compare every pair of elements.

Example:

```
nums = [2,7,11,15]
target = 9

Check

2 + 7 = 9 ✓

Answer found.
```

But consider

```
n = 10,000
```

Comparing every pair requires

```
10000 × 10000
```

comparisons in the worst case.

This is inefficient.

Instead, we can remember numbers we have already seen.

---

# Key Idea
```
Suppose Current number = x
To make target we need `target - x`
If we have already seen `target - x`, then the answer is found immediately.
A **Hash Map** lets us check this in constant time.
```
---

# Algorithm
```
1. Create an empty Hash Map.
2. Traverse the array.
3. For each number (with index):
   * Compute the complement.
   * Check whether the complement exists in the map.
4. If found: * Return both indices.
5. Otherwise:* Store the current number and its index.
6. Continue until the answer is found.
```

# Pseudocode

```
lookup = hashmap()
For each index i from 0 to length-1
    num = nums[i]
    complement = target - nums[i]
    If hashmap[complement]
        return hashmap[complement] and i
    hashmap[num] =  i
Return empty array
```

# Python Solution (LeetCode)

```python
class Solution:
    def twoSum(self, nums, target):
        lookup = {}
        for i in range(len(nums)):
            complement = target - nums[i]
            if complement in lookup:
                return [lookup[complement], i]
            lookup[nums[i]] = i
```

---

# Java Solution (LeetCode)

```java
import java.util.HashMap;

class Solution {
    public int[] twoSum(int[] nums, int target) {
        HashMap<Integer, Integer> map = new HashMap<>();
        for (int i = 0; i < nums.length; i++) {
            int complement = target - nums[i];
            if (map.containsKey(complement)) {
                return new int[]{map.get(complement), i};
            }
            map.put(nums[i], i);
        }
        return new int[]{};
    }
}
```

# C++ Solution (LeetCode)

```cpp
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        unordered_map<int, int> mp;
        for (int i = 0; i < nums.size(); i++) {
            int complement = target - nums[i];
            if (mp.find(complement) != mp.end()) {
                return {mp[complement], i};
            }
            mp[nums[i]] = i;
        }
        return {};
    }
};
```

# Time Complexity
```
Let **n** be the number of elements in the array.
* We traverse the array exactly once.
* Each Hash Map lookup takes **O(1)** on average.
Therefore,
Time Complexity = O(n)
```

---

# Space Complexity
```
The Hash Map may store every element.
Space Complexity = O(n)
```

---

# Why Does This Work?
```
When processing an element, all previously visited numbers are already stored in the Hash Map.
For the current number:
current + complement = target
If the complement exists in the map, we have found the required pair of indices. Since each element is inserted only after checking for its complement, the same element is never used twice.
```
---

# Key Learning Points
```
* Hash Maps are ideal for fast searching.
* Instead of checking all pairs (**O(n²)**), we reduce the problem to a single traversal (**O(n)**).
* The "complement" technique (`target - current`) is a common interview pattern used in many array and hashing problems.
```
---

# Pattern Used
```
**Hashing**

The solution uses a **Hash Map** to store previously seen elements and their indices, allowing constant-time lookup of the required complement.
```
