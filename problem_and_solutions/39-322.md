# LeetCode 322. Coin Change

**Difficulty:** Medium

**Category / Pattern**

* Dynamic Programming

---

## Problem Description

Given coin denominations and a target amount,

return the minimum number of coins needed.

If impossible,

return `-1`.

---

## Example

**Input**

```text
coins = [1,2,5]

amount = 11
```

**Output**

```text
3
```

### Explanation

```text
5 + 5 + 1
```

---

## Observation

The minimum coins for an amount depend on smaller amounts.

---

## Solution Idea

Use Dynamic Programming.

Build answers from

```text
0

↓

1

↓

2

↓

...

↓

amount
```

---

## Algorithm

1. Initialize DP array.
2. Set DP[0] = 0.
3. Try every coin.
4. Update minimum coins.
5. Return answer.

---

```text

DP[0] = 0
```

Here is the translation of your dynamic programming pseudocode (commonly used for the "Coin Change" problem) into Java, C++, and Python.

### Java

```java
import java.util.Arrays;

class Solution {
    public int coinChange(int[] coins, int amount) {
        // Create DP array (initialize with a value greater than any possible answer)
        int[] dp = new int[amount + 1];
        Arrays.fill(dp, amount + 1);
        
        // DP[0] = 0
        dp[0] = 0;
        
        // For each amount
        for (int i = 1; i <= amount; i++) {
            // For each coin
            for (int coin : coins) {
                if (i - coin >= 0) {
                    // Update minimum coins
                    dp[i] = Math.min(dp[i], dp[i - coin] + 1);
                }
            }
        }
        
        // If answer not possible return -1, else Return answer
        return dp[amount] > amount ? -1 : dp[amount];
    }
}

```

### Python

```python
class Solution:
    def coinChange(self, coins: list[int], amount: int) -> int:
        # Create DP array (initialize with a value greater than any possible answer)
        dp = [amount + 1] * (amount + 1)
        
        # DP[0] = 0
        dp[0] = 0
        
        # For each amount
        for i in range(1, amount + 1):
            # For each coin
            for coin in coins:
                if i - coin >= 0:
                    # Update minimum coins
                    dp[i] = min(dp[i], dp[i - coin] + 1)
                    
        # If answer not possible return -1
        if dp[amount] == amount + 1:
            return -1
            
        # Return answer
        return dp[amount]

```
