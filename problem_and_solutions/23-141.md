# LeetCode 141. Linked List Cycle

**Difficulty:** Easy

**Category / Pattern**

* Linked List
* Fast & Slow Pointer

---

## Problem Description
```
Given the head of a linked list, determine whether it contains a cycle.
Return **true** if a cycle exists; otherwise return **false**.
```
---

## Example

```text
1 → 2 → 3 → 4
     ↑     ↓
     ← ← ←
```

Output

```text
true
```

---

## Observation
```
If one pointer moves faster than another,
they will eventually meet inside a cycle.
```
---

## Solution Idea
```
Use two pointers:
    * Slow → moves one step.
    * Fast → moves two steps.
If they meet,
a cycle exists.
If Fast reaches NULL,
there is no cycle.
```
---

## Algorithm
```
1. Initialize slow and fast pointers.
2. Move slow by one node.
3. Move fast by two nodes.
4. If they meet, return true.
5. If fast reaches NULL, return false.
```
---

## Pseudocode

```text
slow = head
fast = head
While fast and fast.next exist
    slow = slow.next
    fast = fast.next.next
    If slow == fast
        Return true
Return false
```

This pseudocode represents Floyd's Cycle-Finding Algorithm (often called the "Tortoise and Hare" algorithm) for detecting a cycle in a linked list (LeetCode 141: Linked List Cycle).

Here are the translations into Java, C++, and Python.

### Java

```java
/**
 * Definition for singly-linked list.
 * class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode(int x) {
 *         val = x;
 *         next = null;
 *     }
 * }
 */
public class Solution {
    public boolean hasCycle(ListNode head) {
        ListNode slow = head;
        ListNode fast = head;        
        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;            
            if (slow == fast) {
                return true;
            }
        }        
        return false;
    }
}
```
