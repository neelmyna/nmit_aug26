# LeetCode 215. Kth Largest Element in an Array

**Difficulty:** Medium

**Category / Pattern**

---

## Problem Description

Given an integer array and an integer `k`, return the **kth largest** element.

---

## Example

**Input**

```text
nums = [3,2,1,5,6,4]

k = 2
```

**Output**

```text
5
```

---

## Observation

We only need the kth largest element,

not the complete sorted array.

A **Min Heap** of size `k` efficiently solves this.

---

## Solution Idea

* Maintain a Min Heap of size `k`.
* Insert every element.
* If heap size exceeds `k`, remove the smallest.
* The heap top becomes the kth largest element.

---

## Algorithm

1. Create Min Heap.
2. Insert every element.
3. Remove smallest if heap size exceeds `k`.
4. Return heap top.

---

## Pseudocode

```text
Create Min Heap
For each element
    Insert into heap
    If heap size > k
        Remove smallest
Return heap top
```

# Implementation
Here are the translations of your Min Heap logic into Python, Java, and C++. This is the optimal O(N log K) time and O(K) space complexity solution for finding the "Kth Largest Element in an Array".

### Python

```python
import heapq
def find_kth_largest(nums: list[int], k: int) -> int:
    # Create Min Heap
    min_heap = []    
    # For each element
    for num in nums:
        # Insert into heap
        heapq.heappush(min_heap, num)        
        # If heap size > k, remove smallest
        if len(min_heap) > k:
            heapq.heappop(min_heap)            
    # Return heap top
    return min_heap[0]
```

### Java

```java
import java.util.PriorityQueue;
class Solution {
    public int findKthLargest(int[] nums, int k) {
        // Create Min Heap (PriorityQueue is a min-heap by default in Java)
        PriorityQueue<Integer> minHeap = new PriorityQueue<>();        
        // For each element
        for (int num : nums) {
            // Insert into heap
            minHeap.add(num);            
            // If heap size > k, remove smallest
            if (minHeap.size() > k) {
                minHeap.poll();
            }
        }        
        // Return heap top
        return minHeap.peek();
    }
}

```

### C++

```cpp
#include <vector>
#include <queue>
class Solution {
public:
    int findKthLargest(std::vector<int>& nums, int k) {
        // Create Min Heap (std::priority_queue is a max-heap by default, so we use std::greater)
        std::priority_queue<int, std::vector<int>, std::greater<int>> min_heap;        
        // For each element
        for (int num : nums) {
            // Insert into heap
            min_heap.push(num);            
            // If heap size > k, remove smallest
            if (min_heap.size() > k) {
                min_heap.pop();
            }
        }        
        // Return heap top
        return min_heap.top();
    }
};
```
